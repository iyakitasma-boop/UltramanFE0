YOUR OWN CONTROL ICONS (optional) - transparent PNGs, any size (square is best).

Control ids: attack strong jump guard beam dash select pause

  <id>.png          replaces the symbol drawn on the control (the glass body stays)
  <id>_full.png     replaces the whole control, including its background

Also:
  stick.png         the movement ring's knob
  stick_full.png    the movement ring's base picture (square)
  dpad.png          the whole menu pad picture

Missing files fall back to the built-in drawing, so you can add them one at a time.
Arrange where everything sits (and which game button each control presses) with
Controls > Edit layout in the app, press "Save file", and put that file at
assets/ui/layout.json to make your arrangement the default.
This README is not shipped inside the APK.
