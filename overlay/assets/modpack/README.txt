FULL MODPACK INSIDE THE APK (optional). Unzip your modpack here so its folders sit directly in this folder:

  modpack/TEXTURES/<disc id>/textures.ini + pngs...   -> texture replacements
  modpack/Cheats/cheat.db, <disc id>.ini              -> cheats
  modpack/PLUGINS/...                                 -> plugins
  modpack/SAVEDATA/<save folders>                     -> saves, but only folders that don't exist yet
                                                         (an update never overwrites a player's progress)

The texture folder can be named after any disc ID: it is installed under the disc ID of the game the
player imports, so a mod made for another version of the disc still loads. Installed once per app
version, the first time FIGHT is pressed with Texture mods switched on.
Use a pack made for the same game as your import. This README is not shipped inside the APK.
