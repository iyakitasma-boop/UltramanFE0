TEXTURE MODS (optional) - put the texture pack here so it ships inside the APK.

Any of these layouts works:
  textures/textures.ini + the .png files           (pack contents directly)
  textures/<anything>/textures.ini + .png files    (a single pack folder)
  textures/<disc id>/...                            (folder named after a disc ID; the one matching the
                                                     imported ISO is used)

The pack is copied to the game's texture folder (named after YOUR ISO's disc ID, so a pack made
for another version still loads) the first time you press FIGHT after each app update.
This README is not shipped inside the APK.
